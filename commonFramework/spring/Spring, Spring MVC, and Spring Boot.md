
Spring includes multiple functional modules (mentioned above), the most important of which is the Spring-Core module.
==Spring MVC is a very important module in Spring==, which mainly gives Spring the ability to quickly build Web programs with MVC architecture. MVC is the abbreviation of Model, View, Controller. Its core idea is to organize code by separating business logic, data, and display.

Using Spring for development is too cumbersome. For example, when enabling certain Spring features, you need to use XML or Java for explicit configuration. So, Spring Boot was born!
If you need to build a web program with an MVC architecture, you still need to use Spring MVC as the MVC framework. ==It’s just that Spring Boot simplifies many configurations of Spring MVC== for you, making it truly ready to use out of the box!
