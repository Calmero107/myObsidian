As the name implies, a relational database (RDB) is a database based on a relational model, which shows the relationship between the data stored in the database (one-to-one, one-to-many, many-to-many).

In a relational database, our ==data is stored in various tables (such as user tables), and each row in the table stores a piece of data (such as a user's information).==

Most relational databases use SQL to operate the data in the database. In addition, most relational databases support the four major characteristics of transactions (ACID).
