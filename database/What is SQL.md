
SQL is a structured query language that is specifically used to interact with databases. Its purpose is to provide a simple and effective way to ==read and write data from databases.==

Almost all mainstream relational databases support SQL and are very applicable. In addition, some non-relational databases are also compatible with SQL or use query languages ​​similar to SQL.

SQL can help us:

- Create new databases, data tables, and fields;
- Add, delete, modify, and query data in the database;
- Create new views, functions, and stored procedures;
- Perform simple data analysis on the data in the database;
- Use Hive and Spark SQL to process big data;
- Use SQLFlow for machine learning;
- ……
