
1. **Requirements analysis** : Analyze user needs, including data, functional and performance requirements.
2. **Conceptual structure design** : mainly uses ER model for design, including drawing ER diagram.
3. **Logical structure design** : By converting the ER diagram into a table, the conversion from the ER model to the relational model is achieved.
4. **Physical structure design** : mainly involves selecting appropriate storage structure and access path for the designed database.
5. **Database implementation** : including programming, testing and commissioning
6. **Database operation and maintenance** : system operation and daily maintenance of database.
