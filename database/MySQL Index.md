
An index is a data structure used for fast query and retrieval of data, which can essentially be regarded as a sorted data structure.

*The role of an index is equivalent to the table of contents of a book. For example, when we look up a word in a dictionary, if there is no table of contents, we can only look for the word we need to look up page by page, which is very slow. If there is a table of contents, we only need to find the location of the word in the table of contents first, and then directly turn to that page.*

There are many types of index underlying data structures, common index structures are: B-tree, B+ tree and Hash, red-black tree. In MySQL, b==oth Innodb and MyIsam use B+ tree as the index structure.==
