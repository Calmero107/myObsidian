
Draw ER diagrams to clarify the database design.

**ER diagram,** the full name of which is Entity Relationship Diagram, provides a method for representing entity types, attributes, and relationships.

The ER diagram consists of the following three elements:
- **Entity** : Usually a business object in the real world, but some logical objects can also be used. For example, for a campus management system, there will be entities such as students, teachers, courses, and classes. In the ER diagram, entities are represented by rectangular boxes.
- **Attribute** : This is the property of an entity. Attributes are used to describe the elements that make up an entity. For product design, they can be understood as fields. In ER diagrams, attributes are represented by ovals.
- **Relationship** : the relationship between entities, represented by a diamond in the ER diagram. This relationship not only has business associations, but also can be expressed by numbers to represent the quantitative comparison relationship between entities. For example, a class with multiple students is a relationship between entities.
