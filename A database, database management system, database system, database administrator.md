
- **Database** : A database (DataBase, referred to as DB) is a collection of information or a collection of data managed by a database management system.
- **Database Management System** : Database Management System (DBMS) is a large-scale software that manipulates and manages databases, usually used to create, use and maintain databases.
- **Database system** : A database system (DBS) usually consists of software, database and data administrator (DBA).
- **Database Administrator** : Database Administrator (DBA) is responsible for the overall management and control of the database system.
