In a loop structure, when the loop condition is not met or the number of loops reaches the requirement, the loop will end normally. However, sometimes you may need to terminate the loop early when a certain condition occurs during the loop process, which requires the following keywords:

1. `continue`: means to jump out of the current loop and continue to the next loop.
2. `break`: means to jump out of the entire loop body and continue to execute the statements below the loop.
3. `return`Used to jump out of the current method and end the execution of the method.
