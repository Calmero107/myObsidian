- **Prefix form** (for example `++a`, or `--a`): first increment/decrement the value of the variable, and then use the variable. For example, `b = ++a`first `a`increase by 1, and then assign the increased value to `b`.
- **Suffix form** (such as `a++`or `a--`): Use the current value of the variable first, then increment/decrement the value of the variable. For example, `b = a++`first `a`assign the current value of to `b`, then `a`increment by 1.
