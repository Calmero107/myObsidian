
DNS (Domain Name System) is the first important protocol used when a user uses a browser to access a website. DNS solves **the problem of mapping domain names and IP addresses** .

![[Pasted image 20250109114652.png]]

On a computer, there may be browser DNS cache, operating system DNS cache, and router DNS cache. If none of the above caches can be queried, then DNS comes into play.

The current design of DNS adopts a distributed, hierarchical database structure. **DNS is an application layer protocol that can run on top of UDP or TCP protocol with port 53** .
