
**Protocols running on top of UDP** :
1. **HTTP protocol (HTTP/3.0)** : HTTP/3.0 abandons TCP and uses the UDP-based QUIC protocol instead.
2. **DHCP protocol** : Dynamic Host Configuration Protocol, dynamic configuration of IP address
3. **DNS** : The Domain Name System (DNS) converts human-readable domain names (e.g., [www.baidu.com](http://www.baidu.com) ) into machine-readable IP addresses (e.g., 220.181.38.148). We can think of it as a phone book designed specifically for the Internet. In fact, DNS supports both UDP and TCP protocols.
