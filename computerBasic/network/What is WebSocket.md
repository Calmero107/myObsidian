
WebSocket is a full-duplex communication protocol based on TCP connection, which means that the client and server can send and receive data at the same time.

The WebSocket protocol was born in 2008 and became an international standard in 2011. Almost all mainstream newer browsers support the protocol. However, WebSocket can be used not only in browser-based applications, but also in many programming languages, frameworks, and servers.

The WebSocket protocol is essentially an application layer protocol that is used to make up for the lack of persistent communication capabilities of the HTTP protocol. The client and the server only need to handshake once to directly create a persistent connection between the two and perform two-way data transmission.
