
**NAT (Network Address Translation)** is mainly used to convert IP addresses between different networks. It allows private IP addresses (such as IP addresses used in a local area network) to be mapped to public IP addresses (IP addresses used on the Internet) or vice versa, so that multiple devices in a local area network can access the Internet through a single public IP address.

NAT can not only alleviate the problem of IPv4 address resource shortage, but also hide the actual topology of the internal network, making it impossible for the external network to directly access the devices in the internal network, thereby improving the security of the internal network.
