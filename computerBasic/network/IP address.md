
Each device or domain (such as a computer, server, router, etc.) connected to the Internet is assigned an **IP address (Internet Protocol address)** as a unique identifier. Each IP address is a sequence of characters, such as 192.168.1.1 (IPv4), 2001:0db8:85a3:0000:0000:8a2e:0370:7334 (IPv6).

When a network device sends an IP data packet, the data packet contains **the source IP address** and **the destination IP address** . The source IP address is used to identify the sender device or domain of the data packet, while the destination IP address is used to identify the receiver device or domain of the data packet. This is similar to an email that contains both the destination address and the return address.

Network devices determine the destination of data packets based on the destination IP address and forward the data packets to the correct destination network or subnetwork, thus enabling communication between devices.

This IP address-based addressing method is the basis of Internet communication. It allows data packets to be transmitted between different networks, thus achieving global network interconnection. The uniqueness and globality of IP addresses ensure that every device in the network can be identified and addressed by its unique IP address.
