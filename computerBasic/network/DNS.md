
After typing in the URL, the first important thing comes into play - DNS server resolution. DNS (Domain Name System) is a domain name system that solves **the problem of mapping domain names and IP addresses** . After all, a domain name is just a name that is easy to remember for a website, and the real address of a website is actually an IP address.
