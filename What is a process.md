
==A process is the execution process of a program and is the basic unit of a system running a program==. Therefore, a process is dynamic. When a system runs a program, it is a process from creation, running to extinction.

In Java, when we start the main function, we actually start a JVM process, and the thread where the main function is located is a thread in this process, also called the main thread.
