- Java SE (==Java Core - Dùng làm nền tảng cho các phiên bản khác==) (Java Platform, Standard Edition): Java Platform, Standard Edition, the foundation of the Java programming language, which includes core class libraries and virtual machines that support the development and operation of Java applications. Java SE can be used to build ==desktop applications== or ==simple server applications==.

- Java EE (==Enterprise - Phát triển  các ứng dụng web==) (Java Platform, Enterprise Edition): Java Platform, Enterprise Edition, built on Java SE, includes standards and specifications that support enterprise-level application development and deployment (such as Servlet, JSP, EJB, JDBC, JPA, JTA, JavaMail, JMS). Java EE can be used to build distributed, portable, robust, scalable and secure server-side Java applications, such as Web applications.

Java SE is the basic version of Java, and Java EE is the advanced version of Java.
SE is more suitable for developing desktop applications or simple server applications, while Java EE is more suitable for developing complex enterprise applications or web applications.

- Java ME (==Hệ thống nhúng==) is a micro version of Java, mainly used to develop applications for embedded consumer electronic devices, such as mobile phones, PDAs, set-top boxes, refrigerators, air conditioners, etc. Java ME does not need to be paid special attention to, just know that it exists, ==it is no longer used now==.
